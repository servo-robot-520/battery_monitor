## 1. SMBus 标准命令

BQ28Z610 遵循 Smart Battery System (SBS) 1.1 规范，支持以下标准命令：

| 命令地址 | 名称 | 读/写 | 单位 | 说明 |
|---------|------|------|------|------|
| `0x00` | ManufacturerAccess | R/W | — | 写入子命令，用于访问 Manufacturer 功能 |
| `0x01` | RemainingCapacityAlarm | R/W | mAh / 10mWh | 低电量报警阈值 |
| `0x02` | RemainingTimeAlarm | R/W | min | 低剩余时间报警阈值 |
| `0x03` | BatteryMode | R/W | — | 电池模式选项 |
| `0x04` | AtRate | R/W | mA / 10mW | AtRate 值，用于计算 TTFull / TTEmpty |
| `0x05` | AtRateTimeToFull | R | min | AtRate 下充满时间（65535 = 未充电） |
| `0x06` | AtRateTimeToEmpty | R | min | AtRate 下放空时间（65535 = 未放电） |
| `0x07` | AtRateOK | R | bool | 电池能否以 AtRate 持续供电 10 秒 |
| `0x08` | Temperature | R | 0.1 K | 电池温度（需转换：°C = raw/10 − 273.15） |
| `0x09` | Voltage | R | mV | 电池包总电压 |
| `0x0A` | Current | R | mA | 库仑计电流（正=放电，负=充电） |
| `0x0B` | AverageCurrent | R | mA | 平均电流 |
| `0x0C` | MaxError | R | % | SOC 计算最大误差 |
| `0x0D` | RelativeStateOfCharge | R | % | 相对荷电状态 |
| `0x0E` | AbsoluteStateOfCharge | R | % | 绝对荷电状态 |
| `0x0F` | RemainingCapacity | R | mAh / 10mWh | 剩余容量 |
| `0x10` | FullChargeCapacity | R | mAh / 10mWh | 满充容量 |
| `0x11` | RunTimeToEmpty | R | min | 当前速率下放空时间 |
| `0x12` | AverageTimeToEmpty | R | min | 平均放空时间 |
| `0x13` | AverageTimeToFull | R | min | 平均充满时间 |
| `0x14` | ChargingCurrent | R | mA | 充电器推荐充电电流 |
| `0x15` | ChargingVoltage | R | mV | 充电器推荐充电电压 |
| `0x16` | BatteryStatus | R | — | 电池状态标志 |
| `0x17` | CycleCount | R | 次 | 循环计数 |
| `0x18` | DesignCapacity | R | mAh / 10mWh | 设计容量 |
| `0x19` | DesignVoltage | R | mV | 设计电压 |
| `0x1A` | SpecificationInfo | R | — | SBS 版本信息 |
| `0x1B` | ManufacturerDate | R | — | 生产日期（编码：Day + Month×32 + (Year−1980)×256） |
| `0x1C` | SerialNumber | R | — | 电池序列号 |
| `0x20` | ManufacturerName | R | Block | 制造商名称（块读取） |
| `0x21` | DeviceName | R | Block | 设备名称（块读取） |
| `0x22` | DeviceChemistry | R | Block | 电池化学类型（块读取） |
| `0x23` | ManufacturerData | R | Block | 制造商数据（块读取） |
| `0x3C` | CellVoltage1 | R | mV | 电芯 1 电压 |
| `0x3D` | CellVoltage2 | R | mV | 电芯 2 电压 |
| `0x44` | ManufactureBlockAccess | R/W | — | MAC 块读写通道 |

### 温度转换公式

```
实际温度 (°C) = 原始值 (0.1K) / 10 − 273.15
```

示例：原始值 `2981` → `2981 / 10 − 273.15 = 24.95°C`

## 2. ManufactureAccess / ManufactureBlockAccess

- **ManufactureAccess (`0x00`)**：写入 16 位子命令代码
- **ManufactureBlockAccess (`0x04`)**：读取子命令响应数据

**使用流程：**

1. 向 `0x00` 写入子命令代码（小端序）
2. 等待芯片处理（通常 1ms，部分命令需更长）
3. 从 `0x44` 读取块响应

## 8. ChargingStatus (0x0055)

充电状态标志，返回 16 位数据：

| 位 | 缩写 | 名称 | 说明 |
|----|------|------|------|
| 11 | HV | High Voltage Region | 高压区域 |
| 10 | MV | Mid Voltage Region | 中压区域 |
| 9 | LV | Low Voltage Region | 低压区域 |
| 8 | PV | Precharge Voltage Region | 预充电压区域 |
| 7 | OT | Overtemperature Region | 过温区域 |
| 6 | HT | High Temperature Region | 高温区域 |
| 5 | STH | Standard Temperature High Region | 标准高温区域 |
| 4 | RT | Recommended Temperature Region | 推荐温度区域 |
| 3 | STL | Standard Temperature Low Region | 标准低温区域 |
| 2 | LT | Low Temperature Region | 低温区域 |
| 1 | UT | Undertemperature Region | 欠温区域 |
| 0 | PCHRG | Pre-charge | 预充中 |

### 充电区域判断流程

```
充电电压判断：
  HV: VBV > HVV    （高压区域）
  MV: LVV < VBV ≤ HVV （中压区域）
  LV: PVV < VBV ≤ LVV （低压区域）
  PV: VBV ≤ PVV    （预充电压区域）

充电温度判断：
  OT: T > 60°C     （过温）
  HT: 45°C < T ≤ 60°C （高温）
  STH: TREP < T ≤ 45°C （标准高温）
  RT: TL < T ≤ TREP  （推荐温度）
  STL: 0°C < T ≤ TL  （标准低温）
  LT: TCOLD < T ≤ 0°C （低温）
  UT: T ≤ TCOLD    （欠温）
```

## 23. DataMemoryAccess (0x0040)

数据存储器访问命令，用于读写 Data Flash 中的校准参数和配置数据。

**使用流程：**

1. 向 `0x00` 写入子命令 `0x0040`
2. 向 `0x44` 写入要访问的数据 Flash 地址（2 字节）
3. 等待处理
4. 从 `0x44` 读取数据（块读取）
